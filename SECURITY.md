# Security Policy

## Supported code

Security fixes are made against the latest version on `main`.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Report suspected
vulnerabilities privately through the repository's GitHub Security Advisories
page: <https://github.com/CSVillain/Jifsaw/security/advisories/new>.

Include the affected page or component, steps to reproduce, the impact you
observed, and any suggested mitigation. I will acknowledge reports and provide
an update after triage.

The GIPHY proxy is a public service. Do not include API keys, credentials, or
personal information in a report.
